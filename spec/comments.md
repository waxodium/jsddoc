# JSmm Comments
Comments serve as a program documentation, There are two main forms

1. Line comments start with the character sequence `//` 
and stop at the end of the line.
2. General comments start with the character sequence `/*` and stop
with the first subsequent character sequence `*/`

A comment cannot be placed inside of a 
[string](./types.md#string) or [bytes](./types.md#bytes) literal
