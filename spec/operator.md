### Arithmetic Operators

* `+`: Adds two values.
* `-`: Subtracts the second value from the first.
* `*`: Multiplies two values.
* `/`: Divides the first value by the second.
* `%`: Gives the remainder of a division.
* `++`: Increases a value by one.
* `--`: Decreases a value by one.

### Relational Operators

* `==`: Checks if two values are equal.
* `!=`: Checks if two values are not equal.
* `>`: Checks if the left value is greater.
* `<`: Checks if the left value is smaller.
* `>=`: Checks if the left value is greater or equal.
* `<=`: Checks if the left value is smaller or equal.

### Logical Operators

* `&&`: True if both conditions are true.
* `||`: True if at least one condition is true.
* `!`: Reverses a true or false condition.

### Assignment Operators

* `=`: Assigns a value to a variable.
* `+=`: Adds a value and assigns the result.
* `-=`: Subtracts a value and assigns the result.
* `*=`: Multiplies by a value and assigns the result.
* `/=`: Divides by a value and assigns the result.
* `%=`: Finds the remainder and assigns the result.
* `&=`: Bitwise AND and assign.
* `|=`: Bitwise OR and assign.
* `^=`: Bitwise XOR and assign.
* `<<=`: Left shift and assign.
* `>>=`: Right shift and assign.

### Bitwise Operators

* `&`: Bitwise AND.
* `|`: Bitwise OR.
* `^`: Bitwise XOR.
* `~`: Bitwise NOT (flips bits).
* `<<`: Shift bits left.
* `>>`: Shift bits right.
