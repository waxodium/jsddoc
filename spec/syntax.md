# JSmm Syntax
Introduction to JavaScript-minus-minus syntax. 
The language syntax is fairly similar to Standard [ECMA-262
5.1 Edition](https://262.ecma-international.org/5.1/)

JSmm file extension uses `.js  .jsd  .jsmm`, most used is `.js` and `.jsd`

This language is keyword-based for declarations, with operators and punctuation for structure. 

JSmm types and function declarations rules may differ from C and C-like languages. 
Because it uses **multiple possible return types** but DOES NOT return multiple types at once.
