# jsddoc
Official repository for JSmm programming language test cases, documentations and guides for the entire language.

Involving repository source:
https://github.com/waxodium/jsmm

![License: MIT](./assets/license-mit.svg)

## Getting Started
Check the Installation steps from [jsmm homepage](https://github.com/waxodium/jsmm#home).
Make sure your machines have a met all of the requirments for the installation.

Language stage is still in Bootstrapping phase. Currently written in C++ using `LLVM library` and `glibc 2.44` all relying on `GNU C compiler 16.2.1`

The project major goal is to finish host implementation and Compiler Primitives.

## Joining
Source code is all opensource, free of charge for usage and changes.

In need for kind developers who would volunteerily contributes to the code and language until the turning point happen. 

You can contribute to the jsddoc and the actual JSmm compiler repository. 

For jsddoc, it is based on documentations and test suites. Anyone can make an issue for a feature request, redesign, and make language architectural decisions.
